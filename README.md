## Features

- **Gallery View**: Browse available cats with filtering capabilities
- **Detailed Profiles**: View comprehensive cat information and photos
- **Search Functionality**: Find cats by name, breed, age, and gender
- **Data Export**: Generate CSV exports for recordkeeping
- **Favorites**: Save and track cats of interest in local database
- **ShelterLuv API Integration**: Real-time data from shelter management system

## Technical Details

- Built with .NET MAUI for cross-platform compatibility
- MVVM architecture for clean separation of concerns
- SQLite local database for storing user preferences and favorites
- Responsive UI with proper loading and error states
- See the README PDF for complete documentation

## Notes

This repository is for code review and demonstration purposes only. The application requires a ShelterLuv API key which is not included in this repository for security reasons. The code cannot be run without a valid API key.
